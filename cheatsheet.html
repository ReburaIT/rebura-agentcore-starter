Strands + AgentCore Memory GA · strands-agents-tools

AgentCoreMemoryToolProvider

Built-in Strands tool that wraps the AgentCore Memory API. Stores and retrieves facts that persist across sessions and users.

# 1. Create a memory store
ctrl.create_memory(
  name="agent-memory",
  eventExpiryDuration=86400,        # required, seconds
  memoryExecutionRoleArn=role_arn,
)  # → {"memoryId": "mem-…"}

# 2. Attach to a Strands Agent
from strands_tools.agent_core_memory import AgentCoreMemoryToolProvider

provider = AgentCoreMemoryToolProvider(
  memory_id="mem-…",
  actor_id="user-123",      # scopes memory per user
  session_id="sess-abc",   # scopes memory per session
  namespace="default",
)
agent = Agent(model=…, tools=provider.tools)

Strands Agents SDK v1.0 · OSS · Jul 2025

AWS open-source Python framework. Define tools with a decorator, pass them to an Agent. v1.0 released July 2025 (production-ready). TypeScript support in preview Dec 2025.

# Install
pip install strands-agents strands-agents-tools

# Basic agent
from strands import Agent, tool
from strands.models import BedrockModel

@tool
def get_weather(city: str) -> str:
    """This docstring becomes the tool description."""
    return call_weather_api(city)

agent = Agent(
    model=BedrockModel(model_id="eu.amazon.nova-pro-v1:0"),
    tools=[get_weather],
    system_prompt="You are a helpful weather assistant.",
)
response = agent("What's the weather in Dublin?")

AgentCore Built-in Tools GA

Browser tool GA

Managed Chromium for live web access. Usable via Strands browser tool or directly via boto3.

# Via Strands (recommended)
from strands_tools import browser
agent = Agent(model=…, tools=[browser])

# Via boto3 data plane (AgentCore runtime)
rt.invoke_browser(…)

# Valid action shapes:
{"action": {"type": "navigate", "url": "https://…"}}
{"action": {"type": "get_text"}}        # no extra keys
{"action": {"type": "click",    "coordinate": [x, y]}}
{"action": {"type": "screenshot"}}

Do NOT use selector, session_name, or init_session — sessions are auto-created.

Code Interpreter GA

Sandboxed Python 3. Supports large files, internet access, CloudTrail logging. Pre-installed libs:

# Via Strands (recommended)
from strands_tools import python_repl   # runs locally, not sandboxed
# Or use AgentCore managed sandbox via boto3:
rt.invoke_code_interpreter(…)

# Pre-installed: numpy pandas matplotlib scipy scikit-learn boto3

Identity GA

Workload identity tokens for downstream auth. Secure vault for OAuth refresh tokens. Agents act on behalf of users without long-lived credentials.

# Short-lived workload token:
rt.get_workload_access_token(
  workloadName="my-workload",
)  # → {"workloadAccessToken": "…"}

# On behalf of a user (OIDC federation):
rt.get_workload_access_token_for_jwt(
  workloadName="my-workload",
  jwtToken=user_jwt,
)

Gateway GA

Routes tool calls to Lambda, HTTP APIs, or MCP servers. IAM + OAuth authorization built in.

# Register a gateway (MCP protocol, IAM auth)
ctrl.create_gateway(
  name="my-tools",
  roleArn=role_arn,
  protocolType="MCP",
  authorizerType="AWS_IAM",  # or CUSTOM_JWT / NONE
)
# Returns gatewayId + gatewayUrl for MCP endpoint
# Use gatewayUrl as MCP server URL in Strands mcp_client tool

Patterns & Gotchas

Strands — callback_handler interface

# callback receives **kwargs — all keys are optional:
def my_callback(**kwargs):
  data      = kwargs.get("data", "")         # token text
  complete  = kwargs.get("complete", False)  # True on last chunk
  reasoning = kwargs.get("reasoningText")   # thinking text
  tool_use  = (kwargs.get("event", {})
    .get("contentBlockStart", {})
    .get("start", {})
    .get("toolUse"))                        # tool name + id

Strands — session persistence pattern

# Agent caches history — reuse same object across turns
agent = Agent(model=…, tools=[…])
agent("First message")   # turn 1
agent("Follow-up")       # turn 2 — full context preserved

# For SSE streaming, use a _DelegatingCallback wrapper:
# store agent + mutable callback per session_id, update
# cb._delegate = fresh_writer on each HTTP request

Cross-region inference profiles

# Direct model IDs fail in eu-central-1 without provisioned throughput
# Use the eu. prefix for on-demand capacity:
MODEL = "eu.amazon.nova-pro-v1:0"          # ✓ on-demand
MODEL = "amazon.nova-pro-v1:0"             # ✗ ValidationException

AgentCore Memory — eventExpiryDuration is required

ctrl.create_memory(
  name="…",
  eventExpiryDuration=86400,  # required — omitting → ValidationException
)

Bedrock Agents — must prepare after changes

# After ANY change (instructions, action groups, KB):
ctrl.prepare_agent(agentId=agent_id)
# Wait for agentStatus: PREPARED before invoking
